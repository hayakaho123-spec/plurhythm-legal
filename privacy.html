プライバシーポリシー

dashboard-hub(運営者個人が自分専用に使うダッシュボード)における Google ユーザーデータの扱いを定めます。

取得する情報

  • Google カレンダー: 予定の内容を読み取り、運営者本人の操作に応じて予定を追加・変更します。
  • Google ドライブ: ファイルを読み取り専用で参照し、内容の抜粋を読み取ります。

利用目的

運営者本人の画面に予定とファイルの情報を表示する目的にのみ使います。

保管と共有

  • 取得した情報と認可情報は、運営者が管理するサーバー内にのみ保管します。
  • 第三者への提供、販売、広告への利用は行いません。
  • Google API から得た情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。

削除

Google アカウントの「セキュリティ」→「サードパーティのアクセス」から、いつでも連携を解除できます。解除後、保管している認可情報と取得済みデータは運営者が削除します。ご希望の場合は下記へご連絡ください。
